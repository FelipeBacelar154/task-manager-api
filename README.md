# Task Manager API

A RESTful API for task management with user authentication built with Node.js, Express, and SQLite.

## Technologies

- Node.js
- Express
- SQLite3
- JWT Authentication
- Bcrypt

## Features

- User registration and login
- JWT-based authentication
- Create, read, update and delete tasks
- Each user can only access their own tasks

## Getting Started

### Prerequisites
- Node.js installed

### Installation

```bash
git clone https://github.com/FelipeBacelar154/task-manager-api.git
cd task-manager-api
npm install
```
